# Typography System

Lock typography before generation and use it across the set.

## Required Lock

- Primary text direction: horizontal or vertical.
- Headline and body type categories.
- Chinese-to-English size ratio.
- Alignment and grid.
- Headline maximum lines and characters.
- Subtitle maximum lines.
- Maximum label count.
- Logo position.
- Page margins and decorative-line logic.

## Defaults

- Use horizontal text on at least 80% of pages.
- Allow vertical text on at most one hero or color-story page per set unless the user selects a vertical-led system.
- Keep vertical Chinese headlines to eight characters or fewer.
- Keep the main headline to two lines or fewer.
- Use one proof sentence and up to three labels.
- Parameter, review, care, and guide pages use horizontal text.
- English supports hierarchy and atmosphere; do not duplicate every Chinese line mechanically.
- Keep title placement varied by archetype while maintaining the same grid, margins, fonts, and hierarchy.

## Forbidden Generated Copy

Do not add unspecified field names or placeholders such as:

- 标题 / Title
- 副标题 / Subtitle
- 标注一 / Annotation 1
- 卖点一 / Selling Point 1
- 示例 / Example
- 待补充 / Placeholder, unless the approved design-proposal plan explicitly asks for it

Revise an unrequested interface label or numbering only when it is prominent, misleading, or materially harms reading. Ignore inconsequential decorative microtext that does not change the commerce message.
